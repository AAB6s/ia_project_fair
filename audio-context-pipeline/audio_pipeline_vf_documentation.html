Audio Context Pipeline

Audio event detection, runtime context analysis, and explainable model reporting.

The system uses one final ResNet34 CNN as the core audio-event classifier. Whisper transcription is enabled by default for detected voice segments. Diarization, speech emotion, synthetic-voice screening, and reference-speaker matching remain available but off by default for a controlled demo.

1. End-to-End System

Audio file | +-- Audio preparation | +-- Load file | +-- Resample to 32 kHz mono | +-- Split into 3-second windows | +-- Compute RMS, SNR, clipping, silence, and spectral features | +-- Core CNN classification | +-- Convert each window to a 96-bin log-mel spectrogram | +-- Resize spectrogram to 224 x 224 | +-- Run final ResNet34 event classifier | +-- Output six-class probability vector | +-- Mark close predictions with decision_status and secondary_events | +-- Optional context layer | +-- Voice windows can call Whisper, diarization, emotion, deepfake, and speaker matching | +-- All windows can receive acoustic context, integrity flags, and XAI references | +-- Report layer +-- Timeline table +-- Class confidence summary +-- Optional transcript and speaker fields +-- JSON report for API or backend use
Always activeAudio loading, segmentation, spectrogram conversion, final ResNet34 classification, confidence summary, and JSON output.
Runtime modulesResNet34 always runs. Whisper is enabled by default. pyannote, local speaker grouping, Hugging Face emotion, Hugging Face deepfake screening, and reference-speaker matching are controlled from the demo UI/API.
Reliability layerIntegrity checks identify low energy, clipping, short-file risk, and low-SNR conditions without hiding the CNN prediction.
Output formatEach segment stores timing, top event, all class probabilities, ambiguity status, optional transcript, speaker fields, context flags, and XAI references.

2. CNN Training Workflow

Data collection and preprocessing

Raw sourcesESC-50, UrbanSound8K, RAVDESS, CREMA-D, gunshot, siren, baby cry, and music/background audio.
DeduplicationNear-duplicate files are removed before splitting to reduce leakage risk.
AugmentationTrain-only augmentation balances minority classes for glass_break, baby_cry, and gunshot.
SplitStratified 70 / 15 / 15 train, validation, and test split.

Pretrained ResNet34 branch

Input representation32 kHz waveform windows become 96-bin log-mel spectrogram images.
BackboneResNet34 selected as the final model after comparison with the other candidate branches.
Classifier headDropout, linear projection, ReLU, BatchNorm, second dropout, and six-class output layer.
Fine-tuningFrozen phase followed by full fine-tuning with differential AdamW learning rates and validation-based checkpoint selection.

Explainability and calibration

Grad-CAMHighlights spectrogram regions used by the CNN for class decisions.
LIME-style perturbationMeasures local sensitivity by perturbing spectrogram regions.
Temperature scalingCalibrates confidence and reports expected calibration error.
Visual auditLearning curve, confusion matrix, calibration curve, class report, and top-confusion table.

Export

Checkpointresnet34_final.pt is copied to the demo model folder.
Classesgunshot, glass_break, alarm_signal, human_voice, baby_cry, background.
MetricsAccuracy, macro F1, weighted F1, AUC, ECE, latency, parameter count, and model size.
ArtifactsJSON, CSV, plots, checkpoint, and XAI images are kept in the final output folder.

3. Runtime Decision Tree

The ResNet34 classifier is mandatory. Whisper is enabled by default but only loads for voice segments. The other runtime models are called only when enabled and relevant.

For each audio segment | +-- Run ResNet34 event classifier | +-- gunshot -> timeline event + confidence + XAI reference | +-- glass_break -> timeline event + confidence + XAI reference | +-- alarm_signal -> timeline event + confidence + XAI reference | +-- baby_cry -> timeline event + confidence + XAI reference | +-- background -> context event + confidence | +-- human_voice -> voice event + optional voice modules | +-- If event is human_voice | +-- Transcription enabled -> Whisper tiny/base/small | +-- Local grouping enabled -> local acoustic speaker grouping | +-- pyannote enabled + HF token -> pyannote diarization | +-- HF emotion enabled -> superb/wav2vec2-large-superb-er | +-- HF deepfake enabled -> Vansh180/deepfake-audio-wav2vec2 | +-- Reference folder provided -> local reference-speaker matching | +-- If integrity checks are enabled | +-- clipping, low SNR, silence, low energy, and short-file flags | +-- Final segment record +-- start, end, event, confidence, secondary events, context, optional transcript, optional speaker, optional XAI
